# 도장 만들기

이름을 넣으면 배경이 투명한 도장(인감) PNG를 만들어 주는 웹 프로그램입니다.

## 쓰는 법

`index.html` 을 더블클릭하면 브라우저에서 바로 열립니다. 설치할 것은 없습니다.
웹 서버에 올릴 때도 이 파일 하나만 올리면 됩니다.

글씨체는 구글 폰트에서 받아오므로 **인터넷 연결이 필요**합니다.
연결이 안 되면 컴퓨터에 있는 기본 글씨체로 그려집니다.

## 할 수 있는 것

- 이름(2~4자)부터 `설악고등학교장` 같은 긴 문구까지 자동 배치
  (글자 수에 맞춰 열을 잡고, 전통 순서대로 오른쪽 줄부터 채웁니다)
- 원형·타원 도장은 실제 도장처럼 글자를 테두리 가까이 꽉 채우고,
  모서리에서 살짝 넘치는 획은 테두리 안쪽을 따라 깎아 냅니다
- `인` / `印` / `之印` 자동 붙이기
- **한자 변환** — 한글 이름을 한 글자씩 한자 후보(뜻 포함) 가운데서 골라 바꾸기
- 원형 · 타원 · 둥근사각 · 사각 / 양각(글자가 붉게) · 음각(바탕이 붉게)
- 글씨체 24종(한자 지원 3종 · 한자 전용 5종), 인주 색 선택.
  글씨체는 이름이 아니라 **글씨체마다 지금 설정으로 찍힌 도장 미리보기**를 보고 고릅니다
- **미니멀 / 클래식 이중선 / 붓글씨 낙관** 디자인 프리셋
- **글자 간격** 조절과 양각용 **이중 테두리**
- `글자를 칸에 꽉 채우기`를 끄면 모든 글자에 같은 배율을 적용해 원래 글씨 비율 유지
- 기울기에 맞춰 도장 크기를 자동 조절해 사각 도장의 모서리 잘림 방지
- **잉크 번짐·끊김**, **테두리 울퉁불퉁** 슬라이더로 실제로 찍은 듯한 느낌 조절
- `🎲 다시 찍기` — 설정은 그대로 두고 잉크 얼룩 무늬만 새로 뽑기
- 투명배경 PNG 저장(기본 256 × 256, 최대 2048px) 또는 클립보드로 복사
- **설정 자동 저장** — 창을 닫았다 다시 열어도 마지막 상태 그대로.
  `처음 설정으로` 버튼으로 언제든 되돌립니다.

`빠른 설정`의 **미니멀**은 얇은 선과 넉넉한 여백, **클래식 이중선**은 정갈한 인감,
**붓글씨 낙관**은 자연스러운 손글씨 느낌으로 시작합니다. 이름은 유지되며,
새 디자인 프리셋은 어울리는 인주 색과 보조 글자까지 함께 적용합니다.

전통적인 느낌은 **개인 인감 / 사각 낙관**으로 시작한 뒤
**도장밥 옅게 / 많이 낡은**을 덧씌워 낡은 정도를 바꾸면 편합니다.

## 한글에 붙여넣기

한글에서 투명 이미지의 배경이 검게 나오면 **흰 배경 클립보드 복사 (한글용)**를 사용하세요.
이 복사 방식은 배경이 불투명하므로 도장 뒤의 글자나 표 선을 가립니다.
투명 배경이 필요하면 **투명배경 PNG 저장** 후 한글의 **입력 → 그림 → 그림**으로 삽입하세요.
엑셀 등에서는 기존 **투명 배경 클립보드 복사**를 사용할 수 있습니다.

## 한자 변환

`도장에 넣을 글자` 옆의 **한자 변환** 버튼을 누르면 글자마다 한자 후보가 뜻과 함께 나옵니다.
글자별로 하나씩 고르고 **적용**을 누르면 됩니다. 고르지 않은 글자는 한글 그대로 남습니다.

- 자주 쓰는 한자(KS X 1001, 4,888자)가 먼저 나오고, **인명용 한자 더 보기**를 누르면 대법원 인명용 추가 한자가 나옵니다.
  인명용 추가 한자는 노토 세리프(KR)에 없어서, **인명용 한자까지** 글씨체나 **한자 전용** 글씨체가 아니면
  컴퓨터에 설치된 한자 글꼴(윈도우는 바탕 등)로 그려집니다.
- 이미 한자인 글자를 다른 한자로 바꾸거나 다시 한글로 되돌릴 수도 있습니다.
  여러 음으로 읽는 한자(樂 → 낙·락·악·요)는 음마다 나눠 보여 줍니다.
- 보조 글자가 `인`이면 함께 `印`으로 바꾸는 선택지가, 현재 글씨체가 고른 한자를 못 그리면
  한자 글씨체로 바꾸는 선택지가 기본으로 켜져 있습니다. 인명용 추가 한자를 골랐으면
  **노토 세리프 블랙 · 인명용 한자까지**로 바꿔 줍니다.
- 구글 폰트의 한글 글씨체 가운데 한자를 그릴 수 있는 것은 **노토 세리프**와 **노토 산스**뿐입니다
  (글씨체 목록에 `한자 지원` 표시). 그래서 **한자 전용** 묶음에 일본·번체 중국어 글꼴 5종(붓글씨·해서·옛 명조)을
  넣었습니다. 한글이 없는 글꼴이라 한글 부분은 노토 세리프로 그려지고, 글꼴에 없는 한자는
  노토 세리프 KR → JP 순서로 이어 그립니다. 글씨체와 글자가 맞지 않으면 글씨체 선택 아래에 안내가 뜹니다.

### 한자 사전 자료 출처

한자 사전은 `index.html` 끝의 `hanja-data` 블록에 들어 있고 `tools/build-hanja-data.cjs`가 만듭니다.
(`tools/data/`에 원자료를 내려받은 뒤 `node tools/build-hanja-data.cjs --write` — 자세한 방법은 스크립트 머리 주석)

## 추가된 글씨체

- **동해독도**: 힘 있는 붓글씨로 낙관에 어울립니다.
- **연성**: 부드러운 붓글씨 느낌으로 이름 도장에 어울립니다.
- **나눔펜글씨**: 편안한 손글씨로 서명 느낌을 낼 수 있습니다.
- **구기**: 독특한 획 모양으로 개성 있는 도장을 만들 수 있습니다.
- **기랑해랑**: 굵고 뭉툭한 붓 제목체로 도장·낙관 느낌이 가장 강합니다. "붓글씨 낙관" 프리셋이 이 글씨체를 씁니다.
- **노토 산스 블랙**: 굵은 고딕. 노토 세리프 블랙과 함께 한자를 그릴 수 있는 글씨체입니다.
- **노토 세리프 블랙 · 인명용 한자까지**: 노토 세리프로 그리되, KR 글꼴에 없는 인명용 추가 한자만 같은 디자인의 JP 글꼴로 보완합니다.
- **한자 전용** 묶음: 유지 슈쿠(비문 붓글씨) · 유지 보쿠(먹 붓글씨) · LXGW 원카이(해서체) · 캑터스 클래시컬(옛 명조) · 싯포리 명조 굵게.
  한자 도장·낙관용으로, 한글이 섞이면 한글은 노토 세리프로 그려집니다.

손글씨는 `글자를 칸에 꽉 채우기`를 끄면 본래의 글씨 비율을 살릴 수 있습니다.

## 글씨체를 직접 추가하려면

전서체(篆書體) 같은 도장 전용 글씨체는 구글 폰트에 없습니다.
폰트 파일(.ttf/.otf)을 이 폴더에 넣고 `index.html` 위쪽 주석의 `@font-face` 예시와
`FONTS` 배열 설명을 따라 두 곳만 고치면 목록에 나타납니다.
(폰트 라이선스는 직접 확인하세요.)
