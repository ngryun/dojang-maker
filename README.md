# 도장 만들기

이름을 넣으면 배경이 투명한 도장(인감) PNG를 만들어 주는 웹 프로그램입니다.

## 쓰는 법

`index.html` 을 더블클릭하면 브라우저에서 바로 열립니다. 설치할 것은 없습니다.
웹 서버에 올릴 때도 이 파일 하나만 올리면 됩니다.

글씨체는 구글 폰트에서 받아오므로 **인터넷 연결이 필요**합니다.
연결이 안 되면 컴퓨터에 있는 기본 글씨체로 그려집니다.

## 할 수 있는 것

- 이름(2~4자)부터 `설악고등학교장` 같은 긴 문구까지 자동 배치
  (글자 수에 맞춰 열을 잡고, 전통 순서대로 오른쪽 줄부터 채웁니다)
- `인` / `印` / `之印` 자동 붙이기
- 원형 · 타원 · 둥근사각 · 사각 / 양각(글자가 붉게) · 음각(바탕이 붉게)
- 글씨체 13종, 인주 색 선택
- **잉크 번짐·끊김**, **테두리 울퉁불퉁** 슬라이더로 실제로 찍은 듯한 느낌 조절
- `🎲 다시 찍기` — 설정은 그대로 두고 잉크 얼룩 무늬만 새로 뽑기
- 투명배경 PNG 저장(최대 2048px) 또는 클립보드로 복사
- **설정 자동 저장** — 창을 닫았다 다시 열어도 마지막 상태 그대로.
  `처음 설정으로` 버튼으로 언제든 되돌립니다.

`빠른 설정`의 **개인 인감 / 사각 낙관**으로 시작한 뒤
**도장밥 옅게 / 많이 낡은**을 덧씌워 낡은 정도를 바꾸면 편합니다.

## 글씨체를 직접 추가하려면

전서체(篆書體) 같은 도장 전용 글씨체는 구글 폰트에 없습니다.
폰트 파일(.ttf/.otf)을 이 폴더에 넣고 `index.html` 위쪽 주석의 `@font-face` 예시와
`FONTS` 배열 설명을 따라 두 곳만 고치면 목록에 나타납니다.
(폰트 라이선스는 직접 확인하세요.)
